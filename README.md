# Personal site: quick guide
1. Open this folder in VS Code, install the "Live Server" extension, right-click index.html > Open with Live Server.
2. Edit js/data.js: it controls every page. Add projects by copying a block in PROJECTS.
3. Put photos in images/, your resume at files/resume.pdf. Make sure images are .jpg and under ~500 KB.
4. Deploy: push to GitHub and enable Pages, or drag the folder onto Netlify/Cloudflare Pages, then attach your domain.
